# Lanchonete Delivery (E1 - TDS II)

## Integrantes
- Eduardo
- Daniel Sobral

## Tema
Sistema de Lanchonete Delivery migrado do projeto em Java do 3º bimestre para Dart e Flutter, contendo a modelagem de itens do cardápio (`Item`, `Lanche`, `Bebida`, `Porcao`), clientes, endereços, taxas de entrega e pedidos, além da listagem do cardápio na tela.

## Como rodar o app
No terminal, dentro da pasta do projeto, execute:

```bash
flutter run -d chrome
```

## Uso de IA
Utilizamos inteligência artificial como apoio para revisar a conversão das classes de Java para Dart (parâmetros nomeados com `required`, atributos anuláveis com `?`, encapsulamento com `_` e `get`) e estruturar a listagem na tela com `ListView.builder`, `Card` e `ListTile`.
